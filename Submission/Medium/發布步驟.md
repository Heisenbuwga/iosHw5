# 發布步驟

1. 在 Xcode 執行 App，確認自己理解頁面、資料流與動畫。
2. 檢查 Medium文章草稿.md；將製作心得改成自己的實際經驗。
3. 將 Moonlit-iPhone-demo.mp4 與 Moonlit-iPad-demo.mp4 上傳到自己的 YouTube，建議設為不公開。
4. 在 Medium 建立文章，貼上草稿，並上傳 images 資料夾的截圖。
5. 在示範影片段落貼上 YouTube 連結，確認 GitHub 為 https://github.com/Heisenbuwga/iosHw5。
6. 刪除草稿提醒，檢查格式後發布。
